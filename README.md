# 啵啵的秘密小窝

![啵啵](assets/bobo001.png)

一只圆滚滚的像素小宠物，一间可以慢慢装饰的小窝。喂点心、摸摸头、玩小游戏，也可以陪啵啵种花、做饭、编花环。

## 可以玩什么

- 照顾啵啵的饱腹、心情、体力和亲密度，哄它睡觉、等它醒来。
- 装饰卧室、客厅、厨房、家门口、小院和花圃，随着成长解锁家具。
- 玩星星收集、打地鼠、跳豆腐、猜拳、做菜和拍球，赚星星、完成任务与成就。
- 种花、浇水、收获花材，自由搭配花环；做好的菜可以放进冰箱。
- 查看日历、节日和小店打折日。

离开不会让宠物消失。离线结算最长按 3 天计算，饱腹和心情有保底，睡眠也会离线恢复。

## 运行方式

不需要安装前端依赖。将本仓库作为静态网站托管，或在项目目录运行：

```sh
python3 -m http.server 8080
```

然后用浏览器打开 `http://127.0.0.1:8080/`。Termux 也可以使用同样方式。请保持原来的协议、网址和端口，以继续读取原浏览器的进度。

## 存档与迁移

进度保存在当前浏览器的 localStorage 中，不会自动上传或跨设备同步。页面下方的「存档 · 备份与迁移」可导出、导入完整 JSON 存档；导入前会保存一份本机回退备份。

换浏览器、网址、设备或安装 APK 前，请先导出存档。不要清除网站数据；同网址操作导入时请关闭其他游戏标签页。JSON 存档用于备份与迁移，不是加密文件或防作弊证明。

## 图标与主屏幕

图标由米饭手绘，原图位于 `assets/bobo001.png`。已配置浏览器图标与主屏幕应用图标；能否添加以及具体显示方式由浏览器和系统决定。主屏幕入口不代表游戏已具备离线网页缓存功能。

## 网络与隐私

养成和小游戏不需要服务器账号，也不会上传进度。日历会依次尝试从公开 jsDelivr 镜像读取 NateScarlet/holiday-cn 的当年节假日 JSON：

- https://cdn.jsdelivr.net/gh/NateScarlet/holiday-cn@master/
- https://fastly.jsdelivr.net/gh/NateScarlet/holiday-cn@master/
- https://gcore.jsdelivr.net/gh/NateScarlet/holiday-cn@master/

这些请求不带凭据和来源页面。成功结果缓存 7 天，失败缓存 1 天。断网可继续游戏；2026 年有内置放假安排，其他年份缺少数据时不会推测法定调休。

## 项目结构与调试

`index.html` 为入口；`css/` 保存样式与动画；`js/` 保存游戏模块；`assets/` 保存图标；`site.webmanifest` 提供主屏幕应用信息。无需构建步骤。

调试功能保留：连续点击页脚 5 次可打开面板，用于检查数值、家具位置等。清空进度需要二次确认。
